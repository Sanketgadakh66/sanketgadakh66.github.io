01 · About

Payments, end to end — from checkout button to bank settlement.

I'm Sanket, a full-stack software engineer at Avanish Software Services, where I've spent 3.5+ years inside the machinery that moves money for healthcare practices: card payments, ACH, refunds, invoices, appointments, and the automations that tie them together — all in a regulated, compliance-first environment.

On a healthcare payment processing platform I own features across the whole stack — a Blazor Server staff app, a Blazor WebAssembly client portal (PWA), ASP.NET Core APIs, a Windows-service workflow engine, and the SQL Server underneath it all. I led the platform's migration from ASP.NET MVC to .NET Core and Blazor with zero production downtime, cut query response times 30% with parameterized SQL and Redis caching, and wired Practice Management System integrations that sync appointments and patient data in real time.

The part I'm most excited about: building production agentic AI with the Claude API — staff type "charge John $50" and the system does the rest, invoicing surcharges automatically and cutting manual processing time in half.
